Comienza con Docker a través de ejercicios.

## Objetivos

- comprender los fundamentos de Docker para el desarrollo local
- comprender y practicar la gestión de imágenes y contenedores
  - ejecutar binarios
  - ejecutar servicios
- aprender y practicar la gestión básica de volúmenes y redes

## Prerrequisitos

- debes tener [Docker Desktop](https://docs.docker.com/desktop/) instalado en tu máquina
- trabajaremos con contenedores de Linux; puede ser necesario un conocimiento básico de un sistema operativo (SO)

ℹ️ Nota: Todos los ejercicios se demuestran en Windows utilizando Visual Studio 2022, pero no son específicos de este entorno.

## Ejercicios

Cada directorio contiene un ejercicio que completar:
- el archivo `readme.md` contiene la descripción del ejercicio
- el archivo `readme.md` contiene la solución
- otros archivos en el directorio ilustran el contexto de compilación para un binario o servicio que debe ejecutarse en un contenedor
